# Logogram Helper FR+

Version française améliorée de **Logogram Helper** pour Dalamud / FINAL FANTASY XIV.

Basé sur le projet original de **apetih** : https://github.com/apetih/LogogramHelper

## Fonctionnalités

- Toutes les fonctionnalités et recettes du plugin original.
- `/logo` ouvre ou ferme l'interface, y compris hors d'Eureka.
- Sauvegarde automatique du dernier stock de logogrammes observé dans Eureka.
- Consultation du dernier stock sauvegardé en dehors d'Eureka.
- Noms, descriptions, logogrammes et éclats affichés en français.
- Affichage compact des noms d'actions Logos.
- Indication de l'éclat pouvant fournir chaque logogramme.
- Détails des sources directement dans les fenêtres d'actions Logos.
- Info-bulles des éclats indiquant leur contenu potentiel.

## Installation via dépôt personnalisé

Ajoutez l'URL du dépôt maître dans Dalamud :

`https://raw.githubusercontent.com/Hylieno/DalaLeno/main/pluginmaster.json`

Puis recherchez **Logogram Helper FR+** dans `/xlplugins`.

## Compilation

Ouvrez `LogogramHelper.sln` dans Visual Studio avec l'environnement de développement Dalamud configuré et compilez en `Release | x64`.

Le projet utilise `Dalamud.NET.Sdk/15.0.0`.
